# FEGA XSD Schemas

Official SIEX XML schemas from FEGA (Anexo VI, v3.11.4).

## Sources

- Alta (new submission): FEGA Portal -> Documentacion Tecnica SIEX -> Anexo VI -> XSD Alta
- Modificacion (amendment): FEGA Portal -> Documentacion Tecnica SIEX -> Anexo VI -> XSD Modificacion
- Anulacion (cancellation): FEGA Portal -> Documentacion Tecnica SIEX -> Anexo VI -> XSD Anulacion

## Placeholder schemas

The `.xsd` files in this directory are MINIMAL PLACEHOLDERS generated from the
public SIEX documentation. They are NOT the official FEGA schemas and MUST be
replaced with the real XSD files obtained from FEGA before production use.

To obtain official schemas:
1. Register as a SIEX software provider at https://www.fega.gob.es/
2. Access the Documentacion Tecnica SIEX portal
3. Download the Anexo VI XSD package

The placeholder schemas are sufficient for development and testing the
serialization pipeline.
